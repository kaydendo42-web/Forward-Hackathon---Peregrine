### Important limits — describe honestly

The current app is a **browser-local synthetic-data demo**, not the complete production architecture. Supabase, Google Drive, Xero, scheduler and ATO lodgment are absent. Optional AI, SMTP sending and IMAP reply collection are implemented; real model/mail calls have not yet been verified. AI extraction accepts pasted text, not arbitrary PDFs.

Requests start from deterministic demo rules; optional AI calls return proposals requiring acceptance. Evidence intake supports structured CSVs, not arbitrary PDF/image OCR. A client-view toggle is a simulation, **not a permission boundary**. Local activity history is not tamper-proof. Production needs authenticated per-entity server-side transitions, private document storage and durable outbox jobs.

Review export edits only `decision` and `review_note`, not arbitrary adviser adjustments or a full current-year compliance workbook. An immutable accepted FY26 snapshot rolling into FY27 has not been implemented. Do not claim the full annual loop is complete.
