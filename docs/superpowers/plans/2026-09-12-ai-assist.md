# AI Assist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adviser-facing LLM proposals (follow-up wording, extraction from pasted text, reworded questions, change triage) via NVIDIA NIM, applied only through explicit acceptance onto the existing workflow.

**Architecture:** Pure `src/lib/assist.ts` owns schemas, prompt building, reply parsing and acceptance mapping. `src/app/api/assist/route.ts` is a thin, gated proxy to NIM. `src/components/assist-panel.tsx` renders proposals inside the request panel. Deterministic rules stay; the demo works with no key.

**Tech Stack:** Next.js 16 route handler (Node runtime), zod 4, plain `fetch`, Vitest 5, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-12-ai-assist-design.md`

## Global Constraints

- Env names exactly: `NVIDIA_NIM_API_KEY`, `NVIDIA_NIM_MODEL`, `AI_ASSIST_PASSCODE`. Never `NEXT_PUBLIC_`. Never committed.
- NIM endpoint: `https://integrate.api.nvidia.com/v1/chat/completions`, `temperature: 0.1`, 20 s timeout.
- Free text ≤ 20 000 chars; ≤ 20 items per proposal; `promptVersion: 'assist-1'`.
- Nothing applies without an adviser Accept. Audit action on accept: `ai_proposal_accepted`.
- All amounts through `parseMoney`; entity/year/component for extracted rows come from the request, never the model.

export const PROMPT_VERSION = 'assist-1';
export const TASKS = ['follow_up', 'extract', 'reword', 'triage'] as const;

export const assistRequestSchema; // { task, context: AssistContext }
export type AssistContext = { entityName; entityType; financialYear; request: {...summary}; lines?: {...}[]; text?: string };
export type ProposalItem = { follow_up: {text, basis[]}, extract: {documentId, amount|null, description, quote}, reword: {question, basis[]}, triage: {label, note, basis[]} }[T];

export function applyProposalItem(state, request, proposal, index): Workspace; // maps to transitions + logEvent
